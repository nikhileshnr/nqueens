# Screenshots Directory

This directory contains screenshots of the N-Queens Visualizer application.

## Adding Screenshots

1. Take screenshots of the application showing different board sizes and states
2. Name them descriptively (e.g., `8-queens-solution.png`, `backtracking-in-progress.png`)
3. Add them to this directory
4. Update the main README.md to reference these screenshots

## Recommended Screenshots

- Main application view with an 8x8 board
- Solution state for different board sizes
- Backtracking visualization in progress
- Mobile responsive view
